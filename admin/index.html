Comment se connecter

Cliquez sur Sign In Using Access Token et collez votre clé d'accès (elle commence par github_pat_). Le navigateur s'en souviendra.

Première fois ? Créer sa clé d'accès (15 minutes)
  1. Créez un compte gratuit sur github.com/signup.
  2. Activez la double authentification : votre photo en haut à droite → Settings → Password and authentication → Enable two-factor authentication.
  3. Envoyez votre nom d'utilisateur GitHub à Léo, puis acceptez l'invitation reçue par email (Join maisondela).
  4. Ouvrez la page de création de clé et vérifiez :
    • Resource owner : maisondela
    • Repository access : Only select repositories → website
    • Permissions → Contents : Read and write
  5. Cliquez sur Generate token et copiez la clé tout de suite : GitHub ne la montrera plus jamais. Gardez-la dans votre gestionnaire de mots de passe.
Après la connexion
  • Choisissez une rubrique à gauche, modifiez le texte ou ajoutez une image, puis cliquez sur Save.
  • Le site se met à jour tout seul en 2 à 3 minutes.
  • Chaque enregistrement est gardé dans l'historique : une erreur peut toujours être annulée.
En cas de souci
  • Clé refusée : elle a peut-être expiré (au bout d'un an). Créez-en une nouvelle.
  • Clé perdue ou partagée par erreur : supprimez-la sur vos clés GitHub et créez-en une nouvelle.
  • Autre chose : écrivez à Léo.

Votre clé est personnelle : ne la partagez avec personne, même dans l'équipe.
