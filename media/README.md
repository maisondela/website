# Media assets

Source images for the site. Nothing in this folder is published as-is: every image referenced in a template goes through the `@11ty/eleventy-img` transform (configured in `eleventy.config.js`), which generates responsive AVIF/WebP/original derivatives into `_site/img/` at build time. Never commit derivatives; never reference `_site/img/` paths directly.

## Structure

| Folder | Content | Used by |
| --- | --- | --- |
| `logo/` | Very Superflu wordmark: `logo-black.png` (204×90, on light backgrounds), `logo-white.png` (400×195, on dark backgrounds). Low-resolution PNGs recovered from the old site — replace with vector exports if the studio provides them. | Header (black), footer (white) |
| `portraits/color/` | Team photo shoot, color edit. 2592×3872 JPEGs. `-2` suffixes are alternate takes of the same frame. | Creatures page (hover reveal layer) |
| `portraits/mono/` | Same shoot, black-and-white edit. Filenames match `portraits/color/` — this pairing drives the hover color-reveal. | Creatures page (default layer) |
| `artwork/` | Psychedelic visuals from the old site's slider, named by dominant color. | Homepage hero (`pink.avif`), gallery |
| `archive/` | Gitignored. Unused takes (redundant frames, unpaired files) kept locally, out of the repository. Promote a file back by moving it into `portraits/` and adding its slug to `featuredPortraits`. | Nothing |

## Conventions

- Filenames are lowercase kebab-case English (`dsc-8446.jpg`, `logo-white.png`).
- A portrait appears on the Creatures page only if its filename exists in both `portraits/color/` and `portraits/mono/` AND is listed in the curated `featuredPortraits` array in `eleventy.config.js` (redundant takes are excluded there, not deleted).
- The gallery lists everything in `artwork/`.
- Portrait and gallery figures carry an inline blurred placeholder (LQIP) generated by the `lqip` filter in `eleventy.config.js`.

## Optimizing before committing

Camera-size JPEGs (2592×3872, 0.5–1 MB each) are heavier than the site will ever need: the largest rendered width is 800 CSS px (~1600 device px). Before committing new photos, downscale masters to 1600 px wide and recompress (MozJPEG quality 80 — roughly a 70% size cut with no visible loss at site sizes):

- Batch: `node scripts/optimize-media.mjs` (rewrites `media/portraits/**` in place, skips files already ≤1600 px).
- Manual / one-off: <https://squoosh.app/> with MozJPEG, quality 80, resize to 1600 px width.

Keep the untouched camera originals archived outside the repository.

Any change to this folder — adding, removing, renaming files or folders, or changing how they are consumed — must be reflected in this README in the same commit.
